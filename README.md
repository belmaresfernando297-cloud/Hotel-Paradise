## Módulo de habitaciones

- Registro, consulta, modificación y eliminación de habitaciones.
- Validación de números de habitación duplicados.
- Restricción de eliminación de habitaciones con reservaciones activas.

## Interfaz web y navegación

El sistema utiliza templates de Django y una plantilla base
para compartir la barra superior, el menú lateral y el pie de página.

La interfaz utiliza Bootstrap 5 para dar formato a los componentes
y adaptar la distribución al tamaño de la pantalla.

El menú permite navegar entre Dashboard, Habitaciones, Clientes
y Reservaciones.
